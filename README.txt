This script (setupCrossARFMatrix.py) generates an .xcm file that loads in 
both NuSTAR and XRISM data with their respective response files and 
cross-arfs so they can be jointly fit.

There are two .dat files that need to be filled out beforehand.

### obs.dat ###
This file contains all of the information for the NuSTAR and XRISM
data, including the file names, which regions the XRISM data corresponds
to, and how many regions there are.
It is already filled in and can be edited directly OR you can simply make
a copy of it.
It will hopefully be obvious when looking at the file what to put where.
The organization and format of all of the information must remain the 
same, and any lines with a '#' are treated like a comment.

### models.dat ###
This file contains the model definitions. They are in the same format
that we are used to seeing in the .xcm crossarf files. 
Make sure that there are the same number of models as there are regions,
which is defined in 'obs.dat'.
You can place any model in 'models.dat' as long as each parameter is defined
and a constant is placed at the end. 
The code will automatically remap all of the model paramaters to whatever 
models you put in this file, including tie-ing constants across models and 
obsids to have one A and one B constant, as is the style of the nucrossarf 
code. The XRISM data are tied to the A constant, which is fixed at 1.


## Running the Code ##
To actually run the code, assuming that you have setup the '.dat' files
with the correct paths, all you have to do is run the script with 
command-line arguments for the 'obs.dat' and 'models.dat' files, which
enables easy switching between different model setups.

e.g. run:
------------------------------------------------------------
python setupCrossARFMatrix.py obs.dat models.dat
------------------------------------------------------------

This will generate an .xcm file in your designated location (specified
in 'obs.dat') that you can edit and run like a standard crossarf .xcm
file generated by nucrossarf.
